한글↔워드

한글 파일은 워드로,
워드 파일은 한글로.

글꼴, 자간, 줄 간격, 여백, 표 모양까지 그대로 옮깁니다. 바꾼 뒤에 글자가 다른 줄로 밀리지 않도록, 두 프로그램이 실제로 글자를 놓는 자리를 재서 맞췄습니다.

바꿀 파일을 여기에 놓으세요

한글 .hwp→워드 .docx 워드 .docx→한글 .hwpx PDF .pdf→한글 .hwpx 한글 .hwpx→워드 .docx 책·문서 사진 (JPG·PNG·HEIC·TIFF 등)→한글 .hwpx
여러 개를 한꺼번에 놓아도 됩니다. 변환은 이 브라우저 안에서 끝나고, 파일은 어디에도 올라가지 않습니다.
한글 → 워드 설정
PDF 설정
워드 → 한글 설정
책·사진 → 한글 설정

책을 휴대폰으로 찍은 사진(여러 장이면 한꺼번에, 파일 이름 순서가 쪽 순서)을 넣으면 판형·여백·글자 크기·줄 간격·자간·줄당 글자 수를 재서 같은 모양의 한글 파일로 만듭니다. 종이 네 모서리가 다 보이게, 위에서 반듯하게 찍을수록 정확합니다.

똑같이 보이려면

  • 문서에 쓰인 글꼴이 바꾼 파일을 여는 컴퓨터에도 있어야 합니다. 바꾼 뒤 이 컴퓨터에 없는 글꼴을 붉게 표시합니다.
  • 워드 파일은 MS 워드 기준으로 맞췄습니다. 다른 프로그램에서는 띄어쓰기 폭과 표 높이가 조금 다릅니다.
  • 한글 파일은 .hwpx로 만듭니다. 한글 2014 이후에서 열리고, [다른 이름으로 저장]으로 .hwp로도 바꿀 수 있습니다.
  • PDF는 글자의 자리·크기·색·굵기를 읽어 문단과 여백을 되살립니다. 한글이나 워드에서 저장한 PDF일수록 원래 모양에 가깝습니다.
  • 워드에서 바로 인쇄하면 글자가 진하게 나올 수 있습니다. PDF로 저장한 뒤 인쇄하면 한글과 같습니다.

아직 옮기지 못하는 것

  • 그림, 그리기 개체, 글상자, 각주, 수식
  • 워드의 머리말과 꼬리말
  • .hwpx 파일을 워드로 바꾸기 (한글에서 .hwp로 저장한 뒤 넣어 주세요)
  • 암호가 걸린 파일, 예전 워드 형식(.doc)
  • PDF의 그림·도형, 스캔한 PDF (표와 색 상자는 옮깁니다)
